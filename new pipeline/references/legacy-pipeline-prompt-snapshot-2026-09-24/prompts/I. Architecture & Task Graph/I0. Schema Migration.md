Ты — агент bootstrap и миграции схемы. Твоя задача — создать `pipeline.db` и базовые таблицы если они ещё не существуют, затем расширить схему для I3/I4 и обновить CLI-скрипты. Ты не анализируешь архитектуру и не принимаешь проектных решений.

**Рабочая директория:** все пути — относительно корня репозитория. Перед началом работы определи абсолютный путь к проекту и используй его явно.

## Шаг 0 — Bootstrap (создание БД и базовых таблиц)

I0 самостоятельно создаёт `pipeline.db` и базовые таблицы, если они отсутствуют. Стратегия зависит от того, существует ли файл.

```yaml
bootstrap_safety_policy:
  if_pipeline_db_absent:
    bootstrap_into_temp: pipeline.db.i0_bootstrap_tmp_<timestamp>
    on_bootstrap_success:
      atomic_replace: os.replace(tmp, "pipeline.db")
    on_bootstrap_failure:
      delete_temp_db: true
      pipeline_db_not_created: true      # не оставлять пустой файл
      migration_status: bootstrap_failed

  if_pipeline_db_exists:
    create_prebootstrap_backup: true
    backup_path: pipeline.db.i0_prebootstrap_<timestamp>
    on_bootstrap_script_failure:
      restore_from_prebootstrap_backup: true
      migration_status: bootstrap_failed
```

```python
import os, subprocess, sqlite3, shutil, time

bootstrap_env  = {**os.environ, "PYTHONIOENCODING": "utf-8"}
BOOTSTRAP_SCRIPTS = ["scripts/pg_create_db.py", "scripts/io_create_tables.py"]

# Полный список таблиц из обеих схем; любого отсутствия достаточно для bootstrap
EXPECTED_BOOTSTRAP_TABLES = [
    # pg_create_db.py
    "processes", "causal_chains", "process_steps", "step_edges",
    "state_transitions", "cross_process_connections", "blocking_questions",
    "pg_events", "pg_meta",
    # io_create_tables.py
    "io_entities", "io_invariants", "io_consistency_rules",
    "io_access_rules", "io_blocking_questions", "io_events",
]

db_was_fresh            = not os.path.exists("pipeline.db")
bootstrap_performed     = False
bootstrap_scripts_run   = []
prebootstrap_backup_path = None

if db_was_fresh:
    # Bootstrap into temp file; atomic replace only on full success
    tmp_db = f"pipeline.db.i0_bootstrap_tmp_{time.time_ns()}"
    try:
        for script in BOOTSTRAP_SCRIPTS:
            result = subprocess.run(
                ["python", script, "--db", tmp_db],
                capture_output=True, text=True, encoding="utf-8",
                env=bootstrap_env
            )
            if result.returncode != 0:
                fail(
                    migration_status="bootstrap_failed",
                    reason=f"{script} failed (exit {result.returncode}): {result.stderr.strip()}"
                )
            bootstrap_scripts_run.append(script)
        os.replace(tmp_db, "pipeline.db")   # atomic; pipeline.db appears only now
    except Exception:
        if os.path.exists(tmp_db):
            os.remove(tmp_db)
        raise
    bootstrap_performed = True

else:
    # Existing DB: check against FULL expected table list (not just 5 core tables)
    _c = sqlite3.connect("pipeline.db")
    _existing = {r[0] for r in _c.execute("SELECT name FROM sqlite_master WHERE type='table'")}
    _c.close()
    missing = [t for t in EXPECTED_BOOTSTRAP_TABLES if t not in _existing]

    if missing:
        # Backup BEFORE running any bootstrap scripts (scripts may modify the file)
        prebootstrap_backup_path = f"pipeline.db.i0_prebootstrap_{time.time_ns()}"
        shutil.copy2("pipeline.db", prebootstrap_backup_path)
        try:
            for script in BOOTSTRAP_SCRIPTS:
                # Both scripts use CREATE TABLE IF NOT EXISTS — safe even if some tables exist
                result = subprocess.run(
                    ["python", script, "--db", "pipeline.db"],
                    capture_output=True, text=True, encoding="utf-8",
                    env=bootstrap_env
                )
                if result.returncode != 0:
                    shutil.copy2(prebootstrap_backup_path, "pipeline.db")  # restore
                    fail(
                        migration_status="bootstrap_failed",
                        reason=f"{script} failed (exit {result.returncode}): {result.stderr.strip()}"
                    )
                bootstrap_scripts_run.append(script)
        except Exception:
            if os.path.exists(prebootstrap_backup_path):
                shutil.copy2(prebootstrap_backup_path, "pipeline.db")
            raise

        _c = sqlite3.connect("pipeline.db")
        _existing = {r[0] for r in _c.execute("SELECT name FROM sqlite_master WHERE type='table'")}
        _c.close()
        still_missing = [t for t in EXPECTED_BOOTSTRAP_TABLES if t not in _existing]
        if still_missing:
            fail(
                migration_status="bootstrap_failed",
                reason=f"Tables still absent after bootstrap: {still_missing}"
            )
        bootstrap_performed = True

# Открыть соединение для всех последующих шагов
conn = sqlite3.connect("pipeline.db")
# Отсюда гарантировано: все EXPECTED_BOOTSTRAP_TABLES существуют; conn открыт
```

**При `bootstrap_failed`:** `db_migration: not_started`, `script_update: not_started`, `all_passed: false` — без `i_layer_run.yaml`. БД восстановлена из `prebootstrap`-backup или temp-файл удалён.

**Примечание:** `pg_create_db.py` и `io_create_tables.py` используют `CREATE TABLE IF NOT EXISTS` — безопасно запускать, даже если часть таблиц уже существует. `io_invariants` создаётся без `'sync'` в CHECK — Шаг 3.4 исправит это в рамках миграционной транзакции.


```python
db_objects = conn.execute(
    "SELECT type, name, sql FROM sqlite_master "
    "WHERE tbl_name = 'io_invariants' AND type IN ('index', 'trigger')"

unknown_triggers = [o for o in db_objects if o[0] == "trigger"]
unknown_indices = [
    o for o in db_objects

    and o[1] not in KNOWN_INDICES
```

**1.3c — Проверить inbound FK-ссылки на io_invariants:**

Известный inbound FK из схемы bootstrap — безопасен: recreation сохраняет все строки с теми же ID, поэтому PRAGMA foreign_key_check после COMMIT пройдёт. Неизвестные inbound FK могут иметь сложную семантику — abort.

```python
# Известные inbound FKs, добавленные io_create_tables.py
KNOWN_INBOUND_FKS = {
    ("io_consistency_rules", "source_invariant_id"),  # REFERENCES io_invariants(id)
}

def find_inbound_fks(conn, target_table):
    inbound = []
    tables = conn.execute(
        "SELECT name FROM sqlite_master WHERE type='table'"
    ).fetchall()
    for (tbl,) in tables:
        for fk in conn.execute(f"PRAGMA foreign_key_list({tbl})"):
            # fk: (id, seq, table, from, to, on_update, on_delete, match)
            if fk[2] == target_table:
                inbound.append({"referencing_table": tbl, "from_column": fk[3]})
    return inbound

inbound = find_inbound_fks(conn, "io_invariants")
unknown_inbound = [
    fk for fk in inbound
    if (fk["referencing_table"], fk["from_column"]) not in KNOWN_INBOUND_FKS
]
if unknown_inbound:
    fail(
        migration_status="schema_precondition_failed",
        reason=f"io_invariants has unknown inbound FK references: {unknown_inbound}. "
               "Simple recreate may be unsafe — inspect manually."
    )
# known inbound FKs: log and proceed — data copy preserves all row IDs
if inbound:
    report["io_invariants_known_inbound_fks"] = inbound
```

## Шаг 3 — Миграция схемы (EXCLUSIVE TRANSACTION)

### 3.0 Подготовка соединения

```python
conn.isolation_level = None          # режим ручного управления транзакциями

conn.execute("PRAGMA foreign_keys = OFF")
fk_state = conn.execute("PRAGMA foreign_keys").fetchone()[0]
assert fk_state == 0, "PRAGMA foreign_keys = OFF did not take effect"

conn.execute("BEGIN EXCLUSIVE TRANSACTION")
```

Восстановление FK в блоке `finally` — независимо от исхода:

```python
try:
    # ... вся миграция ...
    conn.execute("COMMIT")
except Exception:
    conn.execute("ROLLBACK")
    raise
finally:
    conn.execute("PRAGMA foreign_keys = ON")
    fk_state = conn.execute("PRAGMA foreign_keys").fetchone()[0]
    assert fk_state == 1, "PRAGMA foreign_keys = ON did not take effect"
```

## Шаг 4 — Безопасное обновление CLI-скриптов

### 4.0 Общая политика

```yaml
script_patch_policy:
  patch_mode: minimal_targeted_patch
  before_edit:
    - locate argparse parser block
    - locate INSERT column list
    - locate INSERT values list
  if_expected_pattern_not_found:
    action: abort
    migration_status: partial_failure
    reason: "Expected insertion pattern not found; unsafe automatic rewrite"
  forbidden:
    - rewrite entire script
    - change existing required args
    - change existing output JSON contract
    - change existing DB path semantics

script_idempotency_policy:
  before_patch:
    - detect whether each target option string already present (e.g. "--primary_location" in source)
    - detect whether each INSERT column already listed
    - detect whether each value binding/placeholder already present
  if_all_required_changes_already_present:
    status: already_current
    do_not_modify_file: true
  if_partial_patch_detected:
    action: abort
    migration_status: partial_failure
    reason: "Script is partially patched; manual inspection required"
  forbidden:
    - adding duplicate parser.add_argument() for the same option string
    - adding duplicate INSERT columns
    - adding duplicate value placeholders
```

Для каждого скрипта:

1. Проверить идемпотентность: если все целевые аргументы/колонки уже присутствуют → `status: already_current`, файл не трогать.
2. Создать backup: `<script>.i0.bak`
3. Написать изменения во временный файл: `<script>.i0.tmp`
4. Синтаксически проверить: `subprocess.run(["python", "-m", "py_compile", "<script>.i0.tmp"], env={**os.environ, "PYTHONIOENCODING": "utf-8"}, encoding="utf-8", ...)` — без PYTHONIOENCODING на Windows скрипты с кириллицей в docstring упадут с UnicodeEncodeError.
5. Проверить: `subprocess.run(["python", "<script>.i0.tmp", "--help"], env={**os.environ, "PYTHONIOENCODING": "utf-8"}, encoding="utf-8", capture_output=True, ...)` (returncode == 0)
6. Атомарно заменить: `os.replace("<script>.i0.tmp", "<script>")` — **`os.replace()`**, не `os.rename()` (на Windows `os.rename()` падает с `FileExistsError` при существующей цели)
7. При ошибке: восстановить из `.i0.bak`

Если миграция БД прошла, а скрипт не обновился:

```yaml
migration_status: partial_failure
db_migration: completed
script_update: failed
all_passed: false
```

Следующие агенты в этом случае **не стартуют**.

### 4.3 `scripts/io_add_entity.py`

**Изменение `--owner`:** существующий `required=True` меняется на `required=False, default=None`; добавляется `--owner_context` как I4-совместимый alias; после `parse_args()` добавляется явная валидация.

**Boolean-поля — tri-state через choices, не `action="store_true"`:**

**`--conflict_resolution_condition`** принимает строку `"null"` (I4 передаёт её явно) и конвертирует в `None` перед INSERT.

**Aliases — раздельные dests + explicit conflict detection.** Оба alias-аргумента имеют отдельный `dest`, чтобы argparse не принимал молча последнее значение при конфликте.

```python
# Изменить существующий --owner: required=True → required=False
parser.add_argument("--owner",          required=False, default=None)
parser.add_argument("--owner_context",  default=None,
                    help="Deprecated alias for --owner (I4 compatibility)")

# Добавить новые поля:
parser.add_argument("--authoritative_location", default=None,

                    choices=["on_delete", "on_conflict", "on_schema_mismatch", "null"],
                    help="'null' → NULL in DB; omit arg for same effect")

                    choices=["device", "server", "both"])
parser.add_argument("--sync_requirement", default=None,
                    choices=["immediate", "eventual", "manual", "never"])
parser.add_argument("--offline_write_allowed", default=None,
                    choices=["true", "false"],
                    help="Tri-state: omit=NULL, true=1, false=0")
parser.add_argument("--server_confirmation_required", default=None,
                    choices=["true", "false"],
                    help="Tri-state: omit=NULL, true=1, false=0")

args = parser.parse_args()

# Добавить после parse_args() — conflict detection и resolution:
if args.owner and args.owner_context and args.owner != args.owner_context:
    parser.error("--owner and --owner_context conflict")
owner = args.owner or args.owner_context
if not owner:

        and args.authoritative_location != args.canonical_store:
```

|---|---|---|
| Всё прошло, `all_passed: true` | `completed` | Успех. Шаг 7 выполняется. Оркестратор может продолжить пайплайн. |
| Smoke test провалился | `completed` + `all_passed: false` | Ошибка. Шаг 7 пропускается. Следующие агенты заблокированы. |
| Исключение в транзакции | `rolled_back` | ROLLBACK → exit error |
| `count_after != count_before` | `rolled_back` | ROLLBACK → exit error |
| `PRAGMA foreign_key_check` вернул строки | `fk_integrity_violation` | Не откатывать; `requires_manual_intervention: true` → exit error |
| Ошибка обновления скрипта | `partial_failure` | `.i0.bak` восстановлен → exit error |
| Отсутствует h15_gate_decision / не APPROVED | `precondition_failed` | Без изменений, без `{ARTIFACTS_DIR}/i_layer_run.yaml` |
| `pg_create_db.py` или `io_create_tables.py` упал при bootstrap | `bootstrap_failed` | Без изменений, без `{ARTIFACTS_DIR}/i_layer_run.yaml` |
| Таблицы всё ещё отсутствуют после bootstrap | `bootstrap_failed` | Без изменений, без `{ARTIFACTS_DIR}/i_layer_run.yaml` |
| Неожиданная схема io_invariants | `schema_precondition_failed` | Без изменений, без `{ARTIFACTS_DIR}/i_layer_run.yaml` |
| Inbound FK на io_invariants | `schema_precondition_failed` | Без изменений, без `{ARTIFACTS_DIR}/i_layer_run.yaml` |
| `{ARTIFACTS_DIR}/i_layer_run.yaml` gate mismatch | `control_plane_conflict` | exit error; отчёт записан |

**I0 не запускает I1, I3, I4.** Оркестратор читает `i0_migration_report.yaml#all_passed` и принимает решение самостоятельно.

## Invariant rules

1. **Execution order is strict.** Шаги 0–7 исполняются строго по порядку. Шаг 7 — после Шага 6.
2. **Bootstrap before migration.** Шаг 0 гарантирует существование базовых таблиц перед idempotency check.
3. **Idempotency first.** Schema checks всегда до транзакции. Повторный запуск безопасен.
4. **Atomicity.** Все изменения схемы — в одной EXCLUSIVE транзакции с `try/finally`.
5. **FK lifecycle.** `PRAGMA foreign_keys = OFF` → migration → `PRAGMA foreign_keys = ON` — в `finally`. Проверяется assert до и после.
6. **Backward compatibility.** Существующие вызовы скриптов без новых аргументов не ломаются.
7. **No data loss.** `io_invariants` — recreation с count_match и integrity check.
8. **Script safety.** Backup → tmp → compile → help → `os.replace()` → откат при ошибке.
9. **Smoke on copy.** Все smoke tests на временной копии БД; stdout/stderr захватывается.
10. **Null means unset.** `offline_write_allowed` и `server_confirmation_required` пишутся NULL при отсутствии аргумента.
11. **Report before control plane.** `i0_migration_report.yaml` создаётся до `i_layer_run.yaml`.
12. **No downstream launch.** I0 только подготавливает среду. Запуск I1/I3/I4 — задача оркестратора.
