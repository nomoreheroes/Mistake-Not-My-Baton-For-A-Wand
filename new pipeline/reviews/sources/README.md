# Independent review source attachments

Files in this directory are byte-for-byte copies of external conversation attachments supplied by the owner. They are preserved as immutable review evidence; normalized YAML/Markdown review records reference their SHA-256 values and must not claim reviewer metadata absent from the source.

`d0-01-d0-02-owner-disposition-input-03.txt` is deliberately not numbered as a third autonomous review-return: D0-02 limits that loop to two rounds. It is an owner-disposition input containing findings N-01…N-12; its source SHA-256 is `1052e69ee0653423dfa11613f754d3c69b6c069586fcd694474278c06dd1e2fd`.
