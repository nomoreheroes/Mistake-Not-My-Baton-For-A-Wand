# Design-time invocation ledger schema v1

Layer-plan authoring and independent review happen before a project runtime DB exists, so these calls are not written into the fixture or Swarm checkpoint. They are instead recorded in the Pipeline Git ledger `new pipeline/ledgers/design-invocations.yaml`.

The schema binds this Markdown projection through `x-pipeline-projection.path + sha256`.

Each entry binds a stable invocation ID to its plan/version, author or reviewer role, actor/provider/model/profile, timestamps, exact input-manifest and output hashes, review round, fresh-context status and conflict declaration. For `role: independent_reviewer`, `fresh_context: true`, `inherited_author_context: false` and a non-empty `conflict_declaration` are conditionally required by schema. A Layer Architecture Gate receipt is invalid unless its author and reviewer invocation references resolve in this ledger.

Historical calls whose metadata was never captured remain explicitly incomplete; the harness must not synthesize identities or provider/model facts after the event.
